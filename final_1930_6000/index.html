PSA · Pitcher Status Analyzer · how the analysis works

投手狀態監測One broadcast video in, one row per pitch out: pitch count, velocity, delivery type and the pitcher's posture at release.

The input is game video from the center-field camera angle, the view every broadcast uses for pitches. The system finds that view on its own, reads the scorebug for pitch count, velocity and runners, and measures the pitcher at release. The question: is it consistent enough to see a pitcher change across an outing?

How it works

Four passes over the video

1

Find the pitching shot

Each frame is shrunk to 64×36 and compared with a reference center-field frame. Replays, close-ups and dugout shots score low and are skipped.

2

Read the scorebug

macOS text recognition reads the overlay twice a second. After each pitch it shows the velocity, then the pitch count (NP) and ball-strike count update.

Images
3

Track the pitcher's pose

Apple Vision body pose runs on every pitching-shot frame. Release is the frame a learned picker, trained on hand-labeled releases, scores highest in the shot.

4

Join into one row per pitch

Each detected release is matched to the next NP increment on the scorebug, within 8 seconds. Pickoffs and false detections have no NP change, so they drop out. Runners on base mark the pitch as a stretch delivery.

Outing board

How each pitcher changed through the outing

With runners on, pitchers switch from the windup to the stretch, which changes timing and posture. Each pitch is tagged from the base diamond on the scorebug, and the baseline uses the pitcher's own first 10 windup pitches so stretch pitches do not read as drift. Velocity drop is the most consistent within-game fatigue sign in the research. Arm slot is shown for reference only: its change under fatigue (about 1.7°) is smaller than video pose error.

Next steps

  1. Run full-game video for a whole outing (60 to 90 pitches), so every pitch counts, not only the ones a highlight shows.
  2. Solve each camera from the field's lines, so more stadiums can be compared without shared pitchers.
  3. Test PSI against outcomes on more pitchers: a league-wide results check with Rebas data, and known-change events.
  4. Have coaches review the outings PSI flags.
Metrics are for workload and consistency tracking. They are not a medical assessment.
